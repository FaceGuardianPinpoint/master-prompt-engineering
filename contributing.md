## 🛠 Feature Breakdown

### Feature 1 — Prompt Framework
Role, task, context, constraints, format, examples — the six pillars of a good prompt.

### Feature 2 — Pattern Library
Reusable templates for summarization, extraction, classification, rewriting, and code generation.

### Feature 3 — Chain Workflows
Break complex tasks into steps: plan → execute → verify → refine.

### Feature 4 — Agent Patterns
ReAct, tool use, function calling, and multi-agent collaboration.

### Feature 5 — Evaluation Suite
Score prompts for accuracy, consistency, cost, and latency across models.

### Feature 6 — Safety Patterns
Guardrails, prompt injection defenses, and refusal handling.

## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Model ignores prompt** | Shorten and clarify |
| **Output too long** | Add word limit |
| **Wrong format** | Add JSON schema |
| **Tone off** | Add persona |
| **Hallucinations** | Add constraints + examples |
| **Inconsistent results** | Lower temperature |
